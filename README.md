---

## 🚀 How It Works

1. Enter a value in the **Value** field.
2. Select the base you're converting **from**.
3. Select the base you're converting **to**.
4. Click **Convert** to see the result instantly.

**Example**

Input:
```
Value: 255
Convert From: Decimal
Convert To: Hexadecimal
```

Output:
```
Result : FF
```
